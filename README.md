## Timeless and Classics Zero: Refabricated

This mod is an unofficial Fabric port of [TaCZ](https://github.com/MCModderAnchor/TACZ).

**Note:**
- **This mod requires [Forge Config API Port](https://modrinth.com/mod/forge-config-api-port).**
- **This mod is still experimental, perhaps there exist some bugs.**
- **<font color="red">If you want to load custom gunpacks in MC1.21.1, you can upgrade gunpacks to be 1.21.1 NeoForge compatible using the pack upgrader mod, which you can find the download link [here](https://discord.com/channels/1243278348399022252/1329058172148645909/1329058172148645909) (join the TaCZ Offical Discord), on the [TaCZ Official Discord](https://discord.gg/uX6TdWUVpA) in the [#community-showcase > Unofficial TaCZ 1.21.1 Forge/NeoForge Port](https://discord.com/channels/1243278348399022252/1329058172148645909) channel. And then try load gunpacks in TACZ-Refabricated-1.21.1.</font>**
- **As for 1.21, you can install [Too Many Shortcuts](https://modrinth.com/mod/too-many-shortcuts) or similar mods to solve keybinding conflicts.**
